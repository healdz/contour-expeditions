## How the site is built

The site is plain static HTML, CSS and JS with no framework. It is generated by a Python script, so the header, footer and cards stay in sync across every page.

- **The generator** is `tools/site-builder/build.py`. Trip content lives in `tools/site-builder/trips.py`.
  - Rebuild every page with: `python3 -I tools/site-builder/build.py .` (run from the repo root)
  - This rewrites all the `.html` files, plus `sitemap.xml` and `robots.txt`. **Edit the generator or `trips.py`, not the generated HTML.** Hand edits to the HTML get overwritten on the next build.
  - The generator reads the current logo markup from `index.html`, so `index.html` must exist before you run it.
  - Assets are cache-busted with a version number (`VER = N` in `build.py`, written as `?v=N` on CSS and JS links). Raise `VER` whenever `styles.css` or `main.js` changes.
- **Styles** are in `assets/css/styles.css`; the CSS variables at the top define the palette and fonts. **Behaviour** is in `assets/js/main.js`: the nav, gallery lightbox, hut calendar, date picker, forms, and Leaflet maps.
- **Local preview:** `python3 -I tools/site-builder/serve.py ~/contour-expeditions 8765`, then open http://127.0.0.1:8765. This server understands clean URLs; the plain `python -m http.server` does not.
- **Visual checks** use headless Chrome (`/Applications/Google Chrome.app/...`) with `--screenshot`. Headless Chrome has a minimum window width of 500px, so test mobile at 500 wide.
- **Clean URLs:** links have no `.html` (`/about`, `/trips/swiss-via-alpina`). GitHub Pages serves the matching `.html` file, so old `.html` links still work.
- **Hidden files:** `_config.yml` excludes `CLAUDE.md`, `README.md` and `tools/` from the published site.

### Swiss Via Alpina (the only fully real trip)
- **Route:** Lauterbrunnen → Rotstockhütte (night 1) → Sefinenfurgge → Gspaltenhornhütte (night 2) → Hohtürli → Blüemlisalphütte (night 3) → Oeschinensee → Kandersteg. The huts are open June through September.
- **Hut calendar:**
  - `tools/hut_availability.py` fetches availability for huts 69 (Rotstock), 44 (Gspaltenhorn) and 1 (Blüemlisalp) from hut-reservation.org.
  - `.github/workflows/hut-availability.yml` runs it every 6 hours and force-pushes the JSON to the `availability-data` branch.
  - A start date is available only when every hut has enough beds for the group on consecutive nights.
  - Dates are unavailable only when a hut is full or closed. Seasons not yet published count as available ("booking opens soon").
  - GitHub pauses scheduled workflows after 60 days with no repo activity. Re-enable it from the Actions tab.
- **Day figures** on the trip page match the trip sheet (total approx. 39 km, +3,500 m). If you change one, change the other (`trips.py` and `tools/trip-sheets/content.py`).
- The "Sample dates" tag is hidden on any trip with `price_confirmed`, so it shows only on the placeholder trips.

### Forms
- **All three forms (contact, reserve, customize) are delivered by FormSubmit (formsubmit.co)**, with no account. `main.js` posts them in the background to `https://formsubmit.co/ajax/<FORM_TO>`. `FORM_TO` in `build.py` is FormSubmit's random alias string for info@ (so the address is not exposed to bots).
  - The hidden `_subject` field names the form ("Website enquiry", "Reservation request", "Custom expedition enquiry"). `_template=table`, and `_honey` is the honeypot.
  - Before sending, the script swaps select values for their visible text (so trip names, not slugs) and joins ticked checkboxes into one line.
  - The owner tried Formspree and Forminit first and chose FormSubmit. The Forminit account (form `g6m5mep91rb`) is unused.
- **The reserve form** has a trip select, a group size, and (for the Swiss trip) start/end date fields that open an "Available Dates" pop-up. It also auto-writes "Hi, I'd like to reserve the Via Alpina for N people starting on DATE." The page accepts the URL parameters `?trip=&start=&group=`.

## Design
- **Theme:** maps. A white background tiled with grey contour lines (`assets/img/contours.svg`, generated by `tools/generate_contours.py`). Text blocks sit on a soft white "halo" so the lines run close to the text without crossing it.
- **Colours:**
  - ink `#1f2326`
  - accent route red `#c8553d`
  - forest green `#3e5c4d`
- **Fonts:** Oswald (headings, uppercase), Inter (body). Bracketed labels like `[ GUIDED ]` are part of the style.
- **Logo:** a hexagon framing stacked contour ridgelines with a red summit dot, used inline in the header and footer and as the favicon. Two alternative logo concepts exist but were not adopted: a plan-view hexagon of contour rings, and a "Contour C". They were saved in `/tmp/ce-logos`, which may be gone.
- **Home cards and top nav:** "Guided Expeditions" and "Unguided Adventures" (nav matches since 2026-11-23). The listing page headings still say "Guided Trips" / "Unguided Trips". Because the nav labels are longer, it switches to the mobile menu below 1024px (`styles.css`); below that width the labels would wrap.

## Photos
- **Where photos go:** real photos live in `assets/img/photos/`. Placeholder SVGs live in `assets/img/placeholders/`.
- **When the owner sends a photo:**
  1. Resize and compress it with `sips`: around 1920px wide for heroes and around 1100–1400px for cards, at JPEG quality 68–72.
  2. Write descriptive alt text.
  3. Point the generator at the photo.
  4. Rebuild and check a screenshot.
- **Cropping:** card crops are adjusted with an inline `object-position` style.

## Client trip sheets (`tools/trip-sheets/`)
- **Output:** the Via Alpina trip sheet is a Word file (for Google Docs) and a PDF, saved in `~/Desktop/Contour Expeditions Trip Sheets/`.
- **Contents:**
  - Cover and At a Glance
  - High-level itinerary
  - Full topo route map
  - One page per day, with a zoomed day map (thin dashed red route with direction arrows) and an elevation profile
  - Getting there and back
  - Packing list
  - Before and after the trip
  - Safety and hut life
- **Pipeline:**
  - `content.py` holds the text.
  - `route.json` holds the trail-following route from the BRouter `hiking-mountain` profile, with waypoints from OpenStreetMap.
  - `map_gen.py` and `day_maps.py` build the map pages, which are rendered with headless Chrome over OpenTopoMap tiles.
  - `profiles.py` builds the elevation profiles.
  - `make_docx.py` (needs `python-docx`) and `make_pdf.py` (HTML printed to PDF by Chrome) build the outputs.
- **Paths:** the scripts use a working folder `/tmp/ce-doc`. Copy them there, or update the paths.
- **Installing the libraries:** create a venv and `pip install python-docx pypdfium2 pillow`.
- **Owner's edits (keep these):**
  - Use "approx." rather than "about".
  - Huts are shared dorms; slippers are not provided, so bring flip-flops or spare shoes.
  - Liner rental is €10 per night. The owner gave euros, but CHF may be correct; still to confirm.
